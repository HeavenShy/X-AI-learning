# Proposal

## Why

底部“复习”标签现在只是一个空状态占位页（`frontend/src/pages/review/index.tsx`）。用户闯关答错的题已经存在服务端的答题记录里，但没有任何入口能再看到、再练这些题，学完就忘。先做一个最小可用的错题本：把答错的题列出来，能重新作答，答对就算掌握、从列表里拿掉。

## What Changes

- 复习页从占位页改为“错题本”：按话（题库标题）分组列出当前用户还没掌握的错题，显示题型、题干和错了几次；没有错题时显示空状态，加载失败可重试。
- 新增“重做错题”页：点开一道错题，按闯关页同样的方式作答并即时判题；展示上次的错误答案、正确答案和讲解。
  - 答对：该题从错题本移除（服务端记为已掌握），回到复习页后不再出现。
  - 答错：留在错题本，错误次数 +1，可以再做一次。
- 新增后端接口（需登录）：
  - `GET /api/v1/review/mistakes`：当前用户未掌握的错题列表。
  - `POST /api/v1/review/answer`：提交一道错题的重做答案，服务端按存档答案判题，答对则标记已掌握。
- 新增数据表 `review_items`，记录每道错题的重做次数与掌握状态；错题本身仍从现有答题记录推导，历史上已经答错的题自动出现在错题本里，无需迁移数据。
- 重做错题**不发**经验和金币（结算规则不变，同一话只结算一次）。

不在本次范围（原型 03 第 7–12 屏中的其余部分）：遗忘曲线排期（第 1/2/4/7/15 天）、“旧识重温”宝藏关与经验翻倍、“已经会了”手动移出、已掌握列表、复习提醒订阅消息、“我的”页错题本入口与红色数字。

## Capabilities

### New Capabilities
- `mistake-review`: 错题本——从用户的答题记录中汇总答错的题，支持重新作答，答对后视为掌握并移出列表。

### Modified Capabilities
（无。现有闯关、结算、历史记录的行为不变。）

## Impact

- 后端：`app/resources/schema.sql`（新表）、`app/core/db.py`（`TABLES`）、新增路由 `app/api/v1/routes/review.py` 并在 `router.py` 注册、新增 service / repository / models，配套测试。
- 前端：`src/pages/review/index.tsx` 重写；新增页面 `src/pages/review-answer/`（并在 `app.config.ts` 注册）；`src/services/api.ts`、`src/types/api.ts` 增加接口与类型；从闯关页抽出判题后的选项展示组件供两处复用；新增纯逻辑与单测。
- 文档：`docs/用户系统方案设计文档.md` 补充接口与表结构说明。
- 无新依赖；不影响未登录 / 无数据库时的出题与报告流程（复习页在这种情况下显示加载失败状态）。
